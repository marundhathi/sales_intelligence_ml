# Sales Intelligence — End-to-End Analytics

An end-to-end retail analytics project analysing 9.1 million rows of 8-year sales data. Combines SQL and Python for data processing, machine learning for predictive insights, and Power BI for business reporting — built during a live data analytics internship on real business data.

## Project Scope

Three interconnected workstreams built on the same dataset:

| Workstream | What it does |
|---|---|
| Data Analysis | SQL + Python on 9.1M+ rows of 8-year sales data |
| Machine Learning | Churn prediction, customer segmentation, market basket analysis |
| Business Intelligence | End-to-end Power BI dashboards across sales, product, branch & category |

---

## Workstream 1 — Data Analysis (Python + SQL)

### What I did
- Consolidated and cleaned 9.1M+ rows of sales data spanning 8 years
- Wrote complex SQL queries to extract sales trends, customer behaviour, and product performance
- Used Python (Pandas) for data transformation, aggregation, and feature engineering
- Identified actionable business insights across regions, product categories, and time periods

### Key analyses
- Year-on-year sales growth and seasonal trends
- Top performing products, categories, and branches
- Customer purchase frequency and recency analysis
- Revenue contribution by division and region

---

## Workstream 2 — Machine Learning Models

### Churn Prediction
- Predicted which customers are at risk of churning based on purchase history and behaviour
- Achieved **87% accuracy** on live sales data
- Output used to flag at-risk customers for the sales team

### Customer Segmentation
- Grouped customers by purchasing behaviour using clustering
- Segments used to personalise sales outreach and promotions
- Helped identify high-value vs low-engagement customer groups

### Market Basket Analysis
- Identified which products are frequently purchased together
- Outputs used to inform product placement, bundling, and cross-sell strategies
- Run on transaction-level data from the full 8-year sales history
